# سایت شخصی امیر صدیقیان

سایت شخصی با فروشگاه و پنل مدیریت کامل.

## ویژگی‌ها
- صفحه اصلی معرفی با مود تاریک/روشن
- فروشگاه هاست، دامنه، سرور و کانفیگ VPN
- سبد خرید و تکمیل سفارش همراه با دریافت آیدی تلگرام مشتری
- اتصال امن به همان رباتی که از پنل وب‌هوک شده، ارسال فاکتور به ادمین و نمایش فاکتور مشتری در ربات
- پنل مدیریت کامل در `/admin` با ویرایشگر ریسپانسیو صفحه «درباره من»
- رابط نئونی و حرکتی، کاملاً ریسپانسیو

## استقرار روی Netlify

### ۱. آپلود روی GitHub
1. یک ریپازیتوری جدید در GitHub بسازید
2. در پوشه پروژه:
```bash
git init
git add .
git commit -m "First commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

### ۲. اتصال به Netlify
1. وارد netlify.com شوید
2. Add new site → Import an existing project → GitHub
3. ریپازیتوری خود را انتخاب کنید
4. Build command: خالی بگذارید
5. Publish directory: خالی بگذارید (یا `.`)
6. Deploy کنید

### ۳. تنظیم ربات تلگرام از پنل
پس از استقرار، وارد `/admin` شوید و در تب «تلگرام» توکن ربات، آیدی چت ادمین و (در صورت نیاز) اطلاعات کارت را وارد کنید. نام کاربری همان ربات به‌صورت خودکار از روی توکن تشخیص داده می‌شود.

با زدن دکمه «ذخیره، تست و فعال‌سازی ربات» سایت به‌صورت خودکار:
- توکن را روی سرور اعتبارسنجی و نام کاربری همان ربات را با `getMe` تشخیص می‌دهد؛
- پیام تست را به چت ادمین می‌فرستد؛
- وب‌هوک `/.netlify/functions/telegram-bot` را روی دامنهٔ فعلی سایت ثبت می‌کند؛
- توکن را در فضای خصوصی Netlify Blobs نگه می‌دارد و در داده‌های عمومی سایت نمایش نمی‌دهد؛
- هنگام ثبت هر سفارش، فعال بودن همین وب‌هوک را دوباره بررسی و «خودترمیم» می‌کند تا کاربر به ربات یا آدرس دیگری منتقل نشود؛ اگر وب‌هوک به دامنهٔ دیگری از همین سایت (مثلاً آدرس netlify.app به‌جای دامنهٔ اختصاصی یا یک دیپلوی‌پریویوی قدیمی) اشاره کند، همان لحظه به آدرس درست سایت فعلی بازنویسی می‌شود و سفارش بدون خطا ثبت می‌گردد.
- اگر ذخیرهٔ تنظیمات در فضای دائمی Netlify Blobs ناموفق باشد، پنل همان لحظه خطا نمایش می‌دهد؛ دیگر حالتی پیش نمی‌آید که تنظیمات «ظاهراً موفق» ذخیره شود اما هنگام سفارش ربات ناشناخته باشد.

> پیش از تست، یک‌بار از حساب ادمین به ربات در تلگرام پیام بدهید تا ربات اجازهٔ ارسال پیام به آن چت را داشته باشد.

### ۴. تنظیم اختیاری متغیرهای محیطی
برای نصب‌های قدیمی یا پیکربندی خارج از پنل، این متغیرها همچنان به‌عنوان جایگزین پشتیبانی می‌شوند: `BOT_TOKEN`، `ADMIN_CHAT_ID`، `BOT_USERNAME`، `PAYMENT_CARD` و `PAYMENT_CARD_HOLDER`.

### ۵. رفع عیب: خطای «تنظیمات در فضای دائمی Netlify Blobs ذخیره نشد»
اگر در پنل ادمین هنگام ذخیرهٔ تنظیمات تلگرام این خطا را دیدید (یا هشدار قرمز «اتصال فضای دائمی (Netlify Blobs) برقرار نیست» زیر وضعیت ربات نمایش داده شد)، یعنی توابع سرورلس نتوانسته‌اند به Netlify Blobs متصل شوند — معمولاً به‌خاطر خطای `MissingBlobsEnvironmentError`، یعنی کانتکست Blobs به تابع تزریق نشده است. کد سایت ابتدا اتصال خودکار را امتحان می‌کند و در صورت شکست، با دو متغیر محیطی زیر دوباره تلاش می‌کند. یک‌بار این دو متغیر را بسازید:

1. **`NETLIFY_BLOBS_SITE_ID`** — همان **API ID** سایت است:
   - در داشبورد Netlify وارد سایت خود شوید؛
   - به مسیر **Site settings → General → Site details** بروید؛
   - مقدار **API ID** را کپی کنید.

2. **`NETLIFY_BLOBS_TOKEN`** — یک **Personal access token**:
   - در داشبورد Netlify روی آواتار کاربری خود کلیک کنید و **User settings** را باز کنید؛
   - به بخش **Applications** بروید؛
   - در قسمت **Personal access tokens** یک توکن جدید (**New access token**) بسازید و مقدار آن را کپی کنید.

سپس هر دو متغیر را در مسیر **Site configuration → Environment variables** همان سایت اضافه کنید و سایت را **Redeploy** کنید (از تب **Deploys** روی آخرین دیپلوی: **Trigger deploy → Deploy site**).

پس از دیپلوی دوباره، هشدار قرمز پنل برداشته می‌شود و ذخیرهٔ تنظیمات تلگرام، داده‌های سایت و سفارش‌ها در فضای دائمی موفق خواهد بود. تا زمانی که این دو متغیر تنظیم نشده‌اند، ذخیره‌سازی در پروداکشن به‌جای «موفقیت ظاهری»، همان لحظه با ذکر دلیل واقعی خطا متوقف می‌شود تا سفارش‌ها بی‌صدا از بین نروند.

## ساختار فایل‌ها
```
├── index.html           # صفحه اصلی
├── shop.html            # فروشگاه
├── projects.html        # نمونه‌کارها
├── about.html           # درباره من
├── contact.html         # تماس
├── admin.html           # پنل مدیریت
├── admin/               # آدرس مخفی /admin/
├── app.js               # منطق اصلی سایت
├── admin.js             # منطق پنل
├── styles.css           # استایل‌ها
├── netlify.toml         # تنظیمات نتلی‌فای
└── netlify/functions/   # توابع سرورلس (ربات تلگرام)
```
